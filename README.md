# alesdi/homebrew-tap

Homebrew formulae for [alesdi](https://github.com/alesdi)'s tools.

```bash
brew install alesdi/tap/spare10
```

## Formulae

| Formula | Description |
|---|---|
| [spare10](https://github.com/alesdi/spare10) | Circuit breaker that pauses Claude Code before its 5-hour quota runs out |

Node.js 20+ is required by `spare10` and is installed as a dependency.
